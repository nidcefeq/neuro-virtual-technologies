# Нейровиртуальные технологии

Учебный репозиторий: лабораторные работы и курсовой проект на Unity. В курсовой игра подстраивает сложность под состояние игрока по полученным метрикам.

Проекты открываются в **Unity 2021.3.45f2**.

## Состав

| Папка | Что внутри |
| --- | --- |
| `LR1` | Лабораторная работа 1. |
| `LR2` | Лабораторная работа 2 |
| `Coursework` | Курсовая: стрельба по уткам, сбор метрик Emotiv и сервис предсказания уровня стресса. |

## Курсовая

Игра в `Coursework/unity` читает performance metrics гарнитуры Emotiv через Cortex и отправляет их на сервис в `Coursework/predictor`. Модель Random Forest отвечает уровнем `low`, `mid` или `high`. Игра инвертирует этот уровень: при низком стрессе утки быстрее и появляются чаще, при высоком — медленнее и реже.

Для живой сессии нужны запущенный Emotiv Cortex, учётные данные приложения и идентификатор гарнитуры. Их задают в компоненте `EmotivMet` на сцене.

Сервис предсказания:

```bash
cd Coursework/predictor
docker compose up -d
```

После запуска проверка доступна по адресу `http://127.0.0.1:8000/health`, предсказание — `POST /predict`.
